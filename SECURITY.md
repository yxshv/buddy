# Security

Buddy can read your screen, run commands and act on your Mac, so security reports matter.

Please **don't open a public issue** for a vulnerability (for example a way to make Buddy run an action without the Touch ID prompt, or to change its permissions or features without approval). Instead, use GitHub's [private vulnerability reporting](https://github.com/yxshv/buddy/security/advisories/new) for this repository.

Include what you did, what happened, and the macOS and Buddy versions. You'll get a reply as soon as possible.
